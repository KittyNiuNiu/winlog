Tasks follow `product-spec.md` (v0.2) and are listed in build order. Each issue title starts with the same number as below, so the order is also visible in the GitHub issue list. Issue numbers and task numbers differ: #1 is a pull request, and #43, #46, #73, #74 and #75 were added later. References such as FR-E1 or §8 in the issues point to the spec.
